
### Wajhati | وجهتي


## About the Project
Wajhati is a tourism events platform designed to provide a seamless experience for both event attendees and event organizers. The platform brings tourism events and their management into one centralized system.

Users can explore available tourism events, view event details, and book events directly through the platform. Their tickets are stored digitally within their account, making them easily accessible whenever needed.

The platform also provides a dedicated dashboard for event organizers and tourism companies. Through the dashboard, organizers can manage their events, view the organizers involved in each event, monitor attendance statistics, and track other event-related information

## Key Features
• Explore and discover tourism events.
 • View event details and available information.
 • Book events online.
 • Store and access tickets digitally.
 • Dedicated dashboard for organizers and tourism companies.
 • Manage events and participating organizers.
 • Monitor attendance statistics and event-related data.
